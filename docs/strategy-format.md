# 戦略ファイル・ハーフタイム指示ファイル 書式仕様

ファイルは Markdown（.md）またはプレーンテキスト（.txt）で記述する。
システムは見出し（`##`）と `キー: 値` の行を読み取る。この仕様に従っていれば、
コメントや意気込みなどを自由に書き足してもよい（パーサーは無視する）。

- 試合前に読み込ませる → **戦略ファイル**（第1部）
- ハーフタイムに読み込ませる → **ハーフタイム指示ファイル**（第2部、任意）

ひな形: [strategies/template.md](../strategies/template.md) /
[strategies/template-halftime.md](../strategies/template-halftime.md)

---

# 第1部 戦略ファイル（試合前）

必須セクション（`##` 見出し）は次の5つ。順不同でよい。

1. `## チーム情報`
2. `## 基本戦術`
3. `## スターティングメンバー`
4. `## 状況別指示`（指示が0個でもセクション自体は必須）
5. `## 切り札`

任意セクション：`## 意気込み`（自由記述、判定に影響しない）

## 1. チーム情報

| キー | 制約 |
|---|---|
| `使用チーム` | `日本` / `ブラジル` / `アルゼンチン` / `スペイン` / `イングランド` / `ドイツ` / `イタリア` / `フランス` / `オランダ` / `ポルトガル` |
| `監督名` | 1〜20文字。実況で使われる |

両者が同じチームを選んでもよい（ミラーマッチ）。
各チームのロスターと能力は `teams/` ディレクトリを参照して選考すること。

## 2. 基本戦術

すべて必須。値は選択肢から**完全一致**で選ぶ。

書き方は2通りあり、どちらでも読み込める:

- **チェックボックス形式**（アプリがダウンロードするファイルの形）: 選択肢が
  `- [ ] ...` で並び、選んだものだけ `- [x] ...` にする（各グループ1つだけ）
- **キー: 値 形式**（手書きする場合に簡単）: `攻撃スタイル: カウンター` のように書く

以下は選択肢の一覧。

| キー | 選択肢 |
|---|---|
| `フォーメーション` | `4-4-2` / `4-3-3` / `3-5-2` / `4-2-3-1` / `5-3-2` |
| `攻撃スタイル` | `ポゼッション` / `カウンター` / `サイドアタック` / `ロングボール` |
| `守備スタイル` | `ハイプレス` / `ゾーン` / `リトリート` / `マンマーク` |
| `ライン設定` | `高い` / `普通` / `低い` |
| `テンポ` | `速い` / `普通` / `遅い` |

### フォーメーションと人数構成

| フォーメーション | 構成(GK-DF-MF-FW) | 中盤スコア | チャンス | 被チャンス |
|---|---|---|---|---|
| 4-4-2 | 1-4-4-2 | ±0 | ±0 | ±0（バランス型） |
| 4-3-3 | 1-4-3-3 | ±0 | +2% | +2%（攻撃型） |
| 3-5-2 | 1-3-5-2 | +2 | ±0 | +1%（中盤支配型） |
| 4-2-3-1 | 1-4-5-1 | +1 | ±0 | −1%（堅実型） |
| 5-3-2 | 1-5-3-2 | −1 | −2% | −4%（守備型） |

## 3. スターティングメンバー

使用チームのロスター（20人）から、フォーメーションの人数構成どおりに
**選手名で**11人を指名する。

```
GK: シミズ
DF: ヤマグチ, スズキ, イノウエ, サトウ
MF: イトウ, ナカムラ, ササキ
FW: マツモト, キムラ, ヤマダ
```

- 選手名はロスターの表記と完全一致させる
- ポジションはロスター登録どおりにしか使えない（DF登録の選手をFW欄に書けない）
- 残りの9人が自動的にベンチ入りする

## 4. 状況別指示（0〜3個）

箇条書きで `IF 条件 THEN 変更` の形式。条件は `AND` で最大3つまで連結できる。

```
- IF 後半 AND ビハインド THEN 攻撃スタイル=ロングボール, ライン設定=高い
- IF 終盤 AND リード THEN 守備スタイル=リトリート, テンポ=遅い
```

### 使える条件

| 条件 | 意味 |
|---|---|
| `前半` / `後半` / `終盤` | 終盤は70分以降 |
| `リード` / `同点` / `ビハインド` | 現在のスコア状態 |
| `2点差リード` / `2点差ビハインド` | 2点以上の差 |
| `主力疲労` | 出場中の選手の平均疲労が60以上 |

### 変更できる項目

`攻撃スタイル` / `守備スタイル` / `ライン設定` / `テンポ`（カンマ区切りで複数同時変更可）

### 発動ルール

- 各ティックの開始時に上から順に条件を評価し、合致した指示をすべて適用する
- 条件が解消されたら基本戦術（後半はハーフタイム指示適用後の戦術）に戻る
- 矛盾する指示が同時に合致した場合は、後に書かれた指示が優先される
- 発動した瞬間は実況で通知される（「ベンチが動いた！」）

## 5. 切り札（必須、1つ選択）

| キー | 内容 |
|---|---|
| `種類` | `スーパーサブ` / `ギアチェンジ` / `鉄壁モード` / `パワープレー` |
| `発動条件` | 状況別指示と同じ条件書式。1試合1回、条件を満たした最初のティックで発動 |
| `指名選手` | `スーパーサブ` の場合のみ必須。ベンチの選手名を1人指名 |

```
種類: スーパーサブ
発動条件: IF 後半 AND ビハインド
指名選手: カトウ
```

- `パワープレー` は80分以降でないと発動しない（条件が先に満たされても待機する）
- `スーパーサブ` の指名選手がハーフタイムまでに出場済み（交代 IN 済み）の場合、
  切り札は不発になる（ハーフタイム指示ファイルで指名を変更できる）

# 第2部 ハーフタイム指示ファイル（任意）

前半終了後、ハーフタイムレポートを見てから読み込ませる。**提出しなければ
前半の戦略のまま後半が始まる。** 変更できるのは以下だけ（制限付き）:

- 選手交代（最大3人）
- 戦術の変更（フォーメーション/攻撃・守備スタイル/ライン/テンポ）
- 状況別指示の全面書き換え
- 切り札の変更（**未使用の場合のみ**）

選手の能力・コンディションは変更できない。

セクションはすべて任意。書いたものだけが適用される。

## 1. 選手交代（最大3人）

```
## 選手交代

- OUT: カトウ → IN: マツモト
- OUT: スズキ → IN: ハヤシ
```

- IN はベンチの選手、OUT は出場中の選手
- **交代後の11人のポジション構成が（変更後の）フォーメーションと一致する**こと。
  同ポジション同士の交代なら常に成立する。ポジション違いの交代は
  フォーメーション変更とセットで構成が合う場合のみ可（例: FW→MF の交代＋4-3-3→4-2-3-1）
- 交代退場した選手は再出場できない
- 交代枠は3。切り札スーパーサブ用の枠は別に1つ確保されている

## 2. 戦術変更

変更したい項目だけを書く。書式・選択肢は戦略ファイルと同じ。

```
## 戦術変更

テンポ: 速い
ライン設定: 高い
```

フォーメーションを変更する場合、出場11人の構成が変更後のフォーメーションと
一致するように交代・配置が成立していなければならない。

## 3. 状況別指示（書き換え）

このセクションを書くと、**前半の状況別指示は破棄され**、ここに書いたもの
（0〜3個）に置き換わる。書かなければ前半のものを引き継ぐ。

```
## 状況別指示

- IF 終盤 AND 同点 THEN ライン設定=高い, テンポ=速い
```

## 4. 切り札（未使用の場合のみ）

前半に発動済みの場合、このセクションは無視される（警告を表示）。

```
## 切り札

種類: パワープレー
発動条件: IF 終盤 AND ビハインド
```

# バリデーションルール（受理条件）

システムは読み込み時に以下をチェックし、違反があれば**理由つきでエラー**を返す。
チェックに通らないファイルでは試合を開始（再開）できない。

## 戦略ファイル

1. 必須セクション5つがすべて存在する
2. `使用チーム` が10チームのいずれかである
3. 基本戦術5項目がすべて選択肢内の値である（表記ゆれ不可。全角/半角に注意）
4. スターティングメンバーが11人で、全員がロスターに実在し、重複がなく、
   ポジション構成がフォーメーションと一致する
5. 状況別指示が3個以下で、条件・変更項目がすべて定義済みの語彙である
6. 切り札が1つだけ指定されている（スーパーサブは指名選手がベンチに実在する)

## ハーフタイム指示ファイル

1. 交代が3人以下で、IN/OUT の選手が実在しそれぞれベンチ/出場中である
2. 戦術変更の値が選択肢内である
3. 交代後の11人の構成が（変更後の）フォーメーションと一致している
   （違反時は交代・フォーメーション変更をまとめて棄却し、他の変更のみ適用）
4. 発動済みの切り札を変更しようとしていない（違反時は該当セクションのみ無視して警告）

# パース仕様（実装者向けメモ）

- 見出し行 `## セクション名` でセクションを切り替える
- セクション内の `キー: 値` 行（全角コロン `：` も許容）、`- IF ...` 行、
  `- OUT: A → IN: B` 行（`→` は `->` も許容）のみ解釈する
- それ以外の行（自由記述・空行・HTMLコメント）はすべて無視する
- 値の前後の空白はトリムする。キーは上記の日本語名で照合する
- 選手名の照合はロスター表記との完全一致（中黒 `・` を含む名前に注意）
