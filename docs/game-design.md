# テキストイレブン ゲームデザイン書

## 1. コンセプト

**「戦略テキストがすべてを決めるサッカーシミュレーション」**

- プレイヤーは監督。試合前に戦略ファイル（Markdown）を書き、キックオフ後は観戦するのみ
- 2人の戦略ファイルをシステムが読み込み、確率的に試合をシミュレートする
- 戦術の相性・能力の配分・状況別指示の設計が勝敗を左右する
- 乱数が絡むため「格上に勝つジャイアントキリング」も起こる

### 遊びの核（コアファン）

1. **執筆の楽しみ**：制約の中で自分の哲学を戦略ファイルに落とし込む
2. **読み合いの楽しみ**：相手の戦略を予想し、相性で上を取る（じゃんけん的駆け引き）
3. **観戦の楽しみ**：手を出せない90分。実況テキストが生むドラマにハラハラする
4. **振り返りの楽しみ**：スタッツを見て「なぜ負けたか」を分析し、次のファイルを改良する

## 2. ゲームフロー

```
[戦略ファイル作成] ×2人
        ↓
[バリデーション]  … 書式・ポイント配分をチェック。違反があればエラーで差し戻し
        ↓
[トス・キックオフ]
        ↓
[前半45分]        … 2分刻み（23ティック）で自動シミュレート、実況を表示
        ↓
[ハーフタイム]    … 戦略ファイルに事前記述した「ハーフタイム指示」を適用
        ↓
[後半45分]        … 23ティック＋アディショナルタイム（1〜3ティック、乱数）
        ↓
[試合結果]        … スコア・スタッツ（支配率/シュート数/決定機）・MVP・戦評
```

- 1ティック = 試合内時間2分。前後半あわせて約46〜49ティック
- 観戦時の表示速度は調整可能（1ティック数秒＝1試合5分程度で観戦できる想定）
- 大会モードでは同点時に延長（Vゴールなし・15分×2）→ PK戦

## 3. 戦略ファイルで決められること（概要）

詳細な書式は [strategy-format.md](strategy-format.md) を参照。

| 項目 | 内容 | 選択肢/制約 |
|---|---|---|
| フォーメーション | 陣形。中盤の枚数などが判定に影響 | 5種から選択 |
| 攻撃スタイル | 攻め方の基本方針 | 4種から選択 |
| 守備スタイル | 守り方の基本方針 | 4種から選択 |
| ライン設定 | 最終ラインの高さ | 高い/普通/低い |
| テンポ | 試合の速度。スタミナ消費と支配率に影響 | 速い/普通/遅い |
| チーム能力 | 6項目に配分 | 各1〜10、**合計36pt** |
| 状況別指示 | 「もし〜なら戦術を変える」ルール | 最大3つ |
| ハーフタイム指示 | 後半開始時に無条件で適用される変更 | 最大1つ |
| 切り札 | 1試合1回だけ発動する特別采配 | 4種から1つ |

### ポイント予算制（公平性の担保）

チーム能力は**合計36ポイント**を6項目（攻撃・守備・スピード・テクニック・スタミナ・メンタル）に
配分する。全項目を最大にはできないため、「何を捨てるか」がチームの個性になる。
バリデーターが合計値と各項目の範囲（1〜10）を機械的にチェックし、違反ファイルは受理しない。

## 4. 試合エンジン（確率モデル）

各ティック（2分）は次の3段階で解決する。

### 4.1 支配権判定 — どちらがボールを持つか

```
中盤スコア = テクニック×2 + フォーメーション中盤補正 + テンポ補正 + スタミナ状態補正 + 1d6
```

両チームの中盤スコアを比較し、高い側がそのティックの「攻撃側」になる。
差が大きいほど支配率が偏る。試合を通じた支配率としてスタッツに記録する。

### 4.2 チャンス生成判定 — 決定機を作れるか

攻撃側について:

```
チャンス確率 = 基本値12%
            + (攻撃側の攻撃力 − 守備側の守備力) × 1.5%
            + 戦術相性補正（下記マトリクス: −10% 〜 +15%）
            + ライン設定の噛み合わせ補正
            + 切り札・状況別指示による補正
```

- チャンス確率は 3%〜35% にクランプする（どんな格差でも「絶対」は起きない）
- 期待値：1チームあたり1試合で決定機5〜8回程度

### 4.3 ゴール判定 — 決定機を沈められるか

```
ゴール確率 = 基本値25%
           + (攻撃力 − 守備力) × 1%
           + メンタル補正（終盤・ビハインド時に効く）
           + 乱れ補正（スタミナ切れ側は失点率上昇）
```

- ゴール確率は 10%〜50% にクランプ
- 期待値：1チーム平均1〜2得点。実際のサッカーに近いスコア分布になる
- 外れた場合は「GKセーブ」「ポスト直撃」「枠外」などを乱数で選び実況に反映

### 4.4 戦術相性マトリクス（攻撃スタイル × 守備スタイル）

チャンス確率への補正。**攻撃側から見た**値。

| 攻撃 ＼ 守備 | ハイプレス | ゾーン | リトリート | マンマーク |
|---|---|---|---|---|
| **ポゼッション** | −10% | ±0 | **+10%** | **+10%** |
| **カウンター** | **+15%** | ±0 | −10% | ±0 |
| **サイドアタック** | ±0 | **+10%** | ±0 | −10% |
| **ロングボール** | **+10%** | −10% | ±0 | ±0 |

**設計意図（読み合いの根拠）**
- ハイプレスは背後にスペースを残す → カウンターとロングボールの裏抜けに弱い
- リトリート（ローブロック）はスペースを消す → カウンターは不発、ただし遅攻ポゼッションに崩される
- マンマークはウインガーを封じる → サイドアタックに強いが、ポジションを流動させるポゼッションに混乱する
- ゾーンは中央のバランス型 → サイドの数的優位（サイドアタック）に弱く、放り込み（ロングボール）には強い

### 4.5 ライン設定の噛み合わせ

| 条件 | 効果 |
|---|---|
| 自軍ライン「高い」 | 自軍チャンス+3%、ただし相手カウンター/ロングボールのチャンス+5% |
| 自軍ライン「低い」 | 相手チャンス−3%、ただし自軍チャンス−3%（攻撃に人数をかけられない） |
| スピード8以上のチームに対しライン「高い」 | 裏抜けリスクさらに+3% |

### 4.6 スタミナモデル

- 各チームはスタミナゲージ100からスタート
- ティックごとに消費：基本2 ＋ テンポ「速い」+1 ＋ ハイプレス採用+1
- 能力「スタミナ」が高いほど消費を軽減（−0.1×スタミナ値/ティック）
- ゲージ30未満で「疲労状態」：中盤スコア−3、失点率+5%
- **ハイプレス×速いテンポは強力だが90分持たない**、が主要なトレードオフになる

### 4.7 メンタルと試合状況

- 70分以降（終盤）：メンタルが低い(4以下)チームはリード時に失点率+5%（逃げ切れない）
- ビハインド時：メンタルが高い(8以上)チームはチャンス確率+3%（粘り強さ）
- PK戦：メンタル×2 + 1d10 の比較を5本繰り返す

## 5. 状況別指示と切り札

### 5.1 状況別指示（if-then ルール、最大3つ）

戦略ファイルに書いた条件が満たされると、戦術が自動で切り替わる。
「監督は観ているだけ」でも采配の意図が試合に現れる、このゲームの中核機能。

```
- IF 後半 AND ビハインド THEN 攻撃スタイル=ロングボール, ライン=高い
```

- 条件：時間帯（前半/後半/終盤=70分以降）、スコア状態（リード/同点/ビハインド）、
  2点差以上、スタミナ30未満 を AND で組み合わせ可能
- 効果：攻撃スタイル/守備スタイル/ライン/テンポ の変更
- 発動した瞬間は実況で通知される（「ベンチが動いた！」）

### 5.2 切り札（1試合1回）

| 切り札 | 効果 | リスク |
|---|---|---|
| スーパーサブ | 発動後15分間チャンス確率+8% | 効果終了後スタミナ消費+1/ティック |
| ギアチェンジ | 発動後10分間、中盤スコア+5 | 終了後5分間、中盤スコア−3 |
| 鉄壁モード | 発動後15分間、被チャンス確率−8% | 期間中、自軍チャンス確率−5% |
| パワープレー | 残り10分から発動可。チャンス確率+12% | 被カウンターのゴール確率+10% |

発動条件も戦略ファイルに事前記述する（例：「75分以降 AND 同点なら発動」）。

## 6. 実況・観戦体験

観戦の面白さはテキスト実況の質で決まる。イベントごとに複数パターンの実況文を用意し、
乱数で選択。チーム名・スタイル名を差し込む。

### 実況ログの例

```
⚽ キックオフ！ レッドファルコンズ vs ブルーオーシャンFC

[前半 06分] ファルコンズがボールを支配。細かいパスで敵陣に迫る
[前半 08分] オーシャンの狙い通りだ！ 奪って一気にカウンター…シュートはGKが正面でキャッチ
[前半 14分] 🟨 オーシャン、たまらずファウルで止める
[前半 22分] ファルコンズ、サイドを変えながら揺さぶる。決定機！ …ああっとポスト直撃！
[前半 37分] ⚽ ゴーーール！！ オーシャンFC、電光石火のカウンター一閃！ 0-1
[HT] ハーフタイム。ファルコンズベンチが動く：ライン設定 → 高い
[後半 71分] 📢 ファルコンズ、切り札「パワープレー」発動！
[後半 74分] ⚽ ゴール！ ファルコンズ、力づくで押し込んだ！ 1-1
[後半 90+2分] オーシャン、最後のカウンター…！ シュートは枠の左へ外れた！
🏁 試合終了 1-1。勝点を分け合う激闘となった
```

### 試合後の出力

- 最終スコア、支配率、シュート数、決定機数、発動した指示・切り札の履歴
- MVP（最も判定に寄与した能力項目から演出的に選出）
- 短い戦評（「ハイプレスがカウンターの餌食になった」等、相性判定の結果を言語化）
- 乱数シードを表示：同じシード＋同じファイルなら同じ試合を再現可能（検証・リプレイ用）

## 7. バランス設計の指針

1. **絶対に勝てる構成を作らない**：相性はじゃんけん構造。どの戦術にも天敵がいる
2. **格差があっても番狂わせ率10〜20%を確保**：確率のクランプ（4.2, 4.3）で保証
3. **強い選択にはコストを付ける**：ハイプレス→スタミナ消費、高ライン→裏のリスク、
   パワープレー→被カウンター
4. **引き分けを許容する**：無理に決着させない（大会モードのみPK）。1試合の軽さを保つ
5. **チューニングは定数表に集約**：相性表・基本確率・クランプ値は設定ファイル化し、
   実装後にシミュレーション（総当たり1万試合など）で勝率の偏りを検証して調整する

## 8. 実装ロードマップ（案）

| フェーズ | 内容 |
|---|---|
| Phase 1 | 戦略ファイルのパーサー＋バリデーター（CLI） |
| Phase 2 | 試合エンジン＋テキスト実況（CLI で1試合流せる） |
| Phase 3 | バランス検証ツール（サンプル戦略同士の総当たりシミュレーション） |
| Phase 4 | Web UI（実況をリアルタイム風に流す観戦画面、戦略ファイルのアップロード） |
| Phase 5 | 拡張：リーグ戦/トーナメント、選手個人パラメータ、天候・ホームアドバンテージ |

## 9. 将来の拡張アイデア

- **選手レベルの記述**：チーム6能力を、11人の選手（各選手に名前と得意技）へ分解
- **スカウティング**：対戦相手の過去の戦略ファイルの一部（戦術のみ等）を試合前に開示
- **シーズンモード**：勝点・得失点差でリーグ戦。連戦によるスタミナ持ち越し
- **観戦者投票**：第三者が実況を見ながら勝敗予想して楽しむモード
