# テキストイレブン ゲームデザイン書

## 1. コンセプト

**「戦略テキストがすべてを決めるサッカーシミュレーション」**

- プレイヤーは監督。国別代表チームを1つ選び、試合前に戦略ファイル（Markdown）を書く
- 2人の戦略ファイルをシステムが読み込み、確率的に試合をシミュレートする
- 監督が介入できるのは **試合前** と **ハーフタイム** の2回だけ。あとは観戦する
- 戦術の相性・スタメン選考・状況別指示・交代采配の設計が勝敗を左右する
- 乱数（コンディション・判定）が絡むため「格上に勝つジャイアントキリング」も起こる

### 遊びの核

1. **執筆の楽しみ**：制約の中で自分の哲学を戦略ファイルに落とし込む
2. **読み合いの楽しみ**：相手のチーム・戦略を予想し、相性で上を取る
3. **観戦の楽しみ**：手を出せない前半45分。実況テキストが生むドラマにハラハラする
4. **修正の楽しみ**：ハーフタイムレポート（スコア・選手の疲労・評価点）を読んで
   交代と戦術修正を打つ。監督の腕の見せ所
5. **振り返りの楽しみ**：スタッツを見て「なぜ負けたか」を分析し、次に活かす

## 2. ゲームフロー

```
[チーム選択＋戦略ファイル作成] ×2人
        ↓
[読み込み＆バリデーション]  … 書式・スタメンの妥当性をチェック。違反はエラーで差し戻し
        ↓
[コンディション抽選]        … 全選手の当日の調子が乱数で決まる（キックオフ時に公開）
        ↓
[前半45分]                  … 2分刻み（23ティック）で自動シミュレート、実況を表示
        ↓
[ハーフタイムレポート]      … スコア・スタッツ・選手ごとの疲労/コンディション/評価点を表示
        ↓
[ハーフタイム指示ファイル読み込み] ×2人（任意）
                            … 選手交代（最大3人）＋制限付きの戦術変更。出さなければ続行
        ↓
[後半45分]                  … 23ティック＋アディショナルタイム（1〜3ティック、乱数）
        ↓
[試合結果]                  … スコア・スタッツ・選手評価点・MVP・戦評
```

- 1ティック = 試合内時間2分。前後半あわせて約46〜49ティック
- 観戦時の表示速度は調整可能（1試合5分程度で観戦できる想定）
- 大会モードでは同点時に延長（15分×2）→ PK戦

## 3. チームと選手モデル

### 3.1 国別代表チーム（10チーム）

日本・ブラジル・アルゼンチン・スペイン・イングランド・ドイツ・イタリア・フランス・
オランダ・ポルトガル。各チームのロスターは `teams/*.md` を参照。

- 各チーム **20人**（GK2・DF7・MF7・FW4）
- 選手は **8能力**（25〜95）を持つ：
  **スピード / パス / ドリブル / シュート / 守備 / 空中戦 / スタミナ / メンタル**
- GKの「守備」はセービング能力を兼ねる

### 3.2 公平性の担保 — 総合値は同一、配分で個性

**スカッド総合値（20人×8能力の合計）は全チーム9000で完全に同一。**
チーム差は「合計」ではなく「配分」にだけ存在する。どのチームを選んでも
地力は同じで、特色を活かす戦術を組めるかが勝負になる。

チームの特色は**どこにも明記しない**。各チームファイルにある短い紹介文の
ニュアンスと、選手のステータスの偏りから読み取る（例：パスとスタミナが
高く空中戦が低ければ「つなぐチーム」だと分かる）。相手がどのチームを
選んだかを見て、その特色を推理するのもスカウティングの一部。

なお、突出したエースを持つチームはベンチが薄い（ベストXIは強いが交代の
カードが弱い）など、配分の偏りは采配面のトレードオフとして現れる。

### 3.3 ロスター生成

ロスターは `tools/generate_teams.py` が生成する（乱数シード固定・再現可能）。
チームごとの「アーキタイプ補正」（合計ゼロ）と分散パラメータで個性を作り、
最後にスカッド総合値を9000へ完全一致させる。バランス調整はこのスクリプトの
定数を変更して再生成する。

### 3.4 コンディション（当日の調子）

キックオフ時に選手ごとに抽選し、全能力に補正がかかる。

| コンディション | 補正 | 確率 |
|---|---|---|
| 絶好調 ☀ | +8% | 10% |
| 好調 🙂 | +4% | 25% |
| 普通 | ±0 | 40% |
| 不調 😐 | −4% | 20% |
| 絶不調 🌧 | −8% | 5% |

- スタメンは**試合前に**戦略ファイルで決めるため、コンディションを見てから
  スタメンを選ぶことはできない（代表監督の宿命）
- ただしハーフタイムには全員のコンディションが見えているので、
  **不調の選手を交代で外す**という采配ができる

### 3.5 疲労とパフォーマンス評価

- 選手ごとに疲労ゲージ（0〜100）を持つ。ティックごとに蓄積:
  基本1.5 ＋ テンポ「速い」+0.5 ＋ ハイプレス採用+0.5（GKは常に0.3）
  − 選手のスタミナによる軽減（スタミナ80なら約3割減）
- 疲労70以上で「重い」状態：その選手の全能力−10%
- 疲労90以上で「限界」状態：全能力−20%、負傷リスク（実況イベント）
- 選手ごとに**評価点**（採点、10点満点）を随時更新：チャンス関与・ゴール・
  アシスト・守備成功・被ゴール関与などから算出。ハーフタイムレポートと
  試合結果に表示され、交代判断の材料になる

### 3.6 チーム能力への変換（エンジン内部）

試合エンジンは従来どおりチーム単位の値で判定する。出場中の11人（コンディション・
疲労補正込み）から毎ティック導出する:

| チーム値 | 導出式（→1〜10スケールに換算） |
|---|---|
| 攻撃力 | FW陣の(シュート×0.5＋ドリブル×0.3＋パス×0.2)×0.65 ＋ MF陣の同値×0.35 |
| 守備力 | DF陣の(守備×0.6＋空中戦×0.4)×0.6 ＋ GKの守備×0.25 ＋ MF陣の守備×0.15 |
| テクニック | MF陣の(パス×0.6＋ドリブル×0.4) |
| 空中戦 | FW陣の空中戦×0.6 ＋ DF陣の空中戦×0.4 |
| スピード / スタミナ / メンタル | 出場11人の平均 |

換算：チーム値 = 導出値 ÷ 10（例：導出値68 → 6.8）

## 4. 戦略ファイルで決められること（概要）

詳細な書式は [strategy-format.md](strategy-format.md) を参照。

| 項目 | 内容 | 選択肢/制約 |
|---|---|---|
| 使用チーム | 10チームから選択 | 両者が同じチームでも可（ミラーマッチ） |
| フォーメーション | 陣形。スタメンの人数構成を決める | 5種から選択 |
| スターティングメンバー | ロスター20人から11人を指名 | フォーメーションと人数整合 |
| 攻撃スタイル | 攻め方の基本方針 | 4種から選択 |
| 守備スタイル | 守り方の基本方針 | 4種から選択 |
| ライン設定 | 最終ラインの高さ | 高い/普通/低い |
| テンポ | 試合の速度。疲労と支配率に影響 | 速い/普通/遅い |
| 状況別指示 | 「もし〜なら戦術を変える」ルール | 最大3つ |
| 切り札 | 1試合1回だけ発動する特別采配 | 4種から1つ |

## 5. ハーフタイム（監督の第2の介入点）

### 5.1 ハーフタイムレポート

前半終了時にシステムが両監督へ表示する:

```
========== ハーフタイムレポート ==========
日本 0 - 1 イタリア   支配率 61% - 39%   シュート 7 - 3   決定機 2 - 2

[日本]  スタメン評価
 # 名前       Pos 疲労  調子  評価
 1 シミズ     GK   14   普通  6.0
 6 スズキ     DF   38   不調  5.5   ← 失点に関与
15 ササキ     MF   52   好調  6.5
18 キムラ     FW   45   絶好調 7.0  ← 決定機2回
 ...
ベンチ: ワタナベ(GK) ハヤシ(DF) ... カトウ(FW/絶不調)
```

### 5.2 ハーフタイム指示ファイル（制限付き）

各監督は後半開始前に**ハーフタイム指示ファイル**を読み込ませられる（任意）。
出さなければ前半の戦略のまま続行。変更できる範囲には制限がある:

| 変更 | 可否 |
|---|---|
| 選手交代 | ✅ 最大3人（ベンチ9人から。交代退場した選手は再出場不可） |
| フォーメーション / 攻撃・守備スタイル / ライン / テンポ | ✅ 変更可 |
| 状況別指示 | ✅ 全面書き換え可（最大3つ） |
| 切り札 | ✅ **未使用の場合のみ**種類・発動条件を変更可 |
| 選手の能力・コンディション | ❌ 変更不可（ロッカールームで足は速くならない） |

交代は疲労リセットの手段でもある：走るサッカー（速いテンポ×ハイプレス）は
前半で選手が消耗するが、ハーフタイムに3枚替えれば後半も走れる。
「飛ばして前半に勝負を仕掛け、後半に入れ替える」といったプランが成立する。

## 6. 試合エンジン（確率モデル）

各ティック（2分）は次の3段階で解決する。チーム値は3.6の導出値
（コンディション・疲労込み）を毎ティック再計算して使う。

### 6.1 支配権判定 — どちらがボールを持つか

```
中盤スコア = テクニック×2 + フォーメーション中盤補正 + テンポ補正 + 疲労状態補正 + 1d6
```

両チームの中盤スコアを比較し、高い側がそのティックの「攻撃側」になる。

### 6.2 チャンス生成判定 — 決定機を作れるか

```
チャンス確率 = 基本値12%
            + (攻撃側の攻撃力 − 守備側の守備力) × 1.5%
            + 戦術相性補正（下記マトリクス: −10% 〜 +15%）
            + スタイル適性補正（6.5）
            + ライン設定の噛み合わせ補正
            + 切り札・状況別指示による補正
```

- 3%〜35%にクランプ（どんな格差でも「絶対」は起きない）
- 期待値：1チームあたり1試合で決定機5〜8回程度

### 6.3 ゴール判定 — 決定機を沈められるか

```
ゴール確率 = 基本値25%
           + (攻撃力 − 守備力) × 1%
           + メンタル補正（終盤・ビハインド時に効く）
           + 疲労補正（消耗した側は失点率上昇）
```

- 10%〜50%にクランプ。期待値：1チーム平均1〜2得点
- 外れは「GKセーブ」「ポスト」「枠外」等を乱数で選び実況へ。関与選手の評価点を更新

### 6.4 戦術相性マトリクス（攻撃スタイル × 守備スタイル）

チャンス確率への補正。**攻撃側から見た**値。

| 攻撃 ＼ 守備 | ハイプレス | ゾーン | リトリート | マンマーク |
|---|---|---|---|---|
| **ポゼッション** | −10% | ±0 | **+10%** | **+10%** |
| **カウンター** | **+15%** | ±0 | −10% | ±0 |
| **サイドアタック** | ±0 | **+10%** | ±0 | −10% |
| **ロングボール** | **+10%** | −10% | ±0 | ±0 |

**設計意図**
- ハイプレスは背後にスペースを残す → カウンター・ロングボールの裏抜けに弱い
- リトリートはスペースを消す → カウンター不発、ただし遅攻ポゼッションに崩される
- マンマークはウインガーを封じる → サイドに強いが、流動的なポゼッションに混乱
- ゾーンは中央バランス型 → サイドの数的優位に弱く、放り込みには強い

### 6.5 スタイル適性補正 — 選手が戦術に合っているか

選んだ戦術と出場選手の能力の一致度がボーナス/ペナルティになる。
**ここがチーム選び＆スタメン選考の核心**（例：空中戦の弱い日本で
サイドアタックを選ぶと弱く、イングランドで選ぶと強い）。

| 採用戦術 | 参照するチーム値 | 補正 |
|---|---|---|
| ポゼッション | テクニック | (テクニック−6)×2% |
| カウンター | スピード | (スピード−6)×2% |
| サイドアタック | 空中戦 | (空中戦−6)×2% |
| ロングボール | 空中戦 | (空中戦−6)×1.5% |
| ハイプレス | スタミナ | 相手チャンス確率へ −(スタミナ−6)×1.5% |

（チーム値は1〜10スケール。6が平均想定）

### 6.6 ライン設定の噛み合わせ

| 条件 | 効果 |
|---|---|
| 自軍ライン「高い」 | 自軍チャンス+3%、ただし相手カウンター/ロングボールのチャンス+5% |
| 自軍ライン「低い」 | 相手チャンス−3%、ただし自軍チャンス−3% |
| 相手スピード8以上でライン「高い」 | 裏抜けリスクさらに+3% |

### 6.7 メンタルと試合状況

- 70分以降（終盤）：メンタル4以下のチームはリード時に失点率+5%（逃げ切れない）
- ビハインド時：メンタル8以上のチームはチャンス確率+3%（粘り強さ）
- PK戦：キッカー個人の(シュート＋メンタル)÷2 + 1d20 vs GKの(守備＋メンタル)÷2 + 1d20

## 7. 状況別指示と切り札

### 7.1 状況別指示（if-then ルール、最大3つ）

```
- IF 後半 AND ビハインド THEN 攻撃スタイル=ロングボール, ライン設定=高い
```

- 条件：時間帯（前半/後半/終盤=70分以降）、スコア状態（リード/同点/ビハインド/
  2点差リード/2点差ビハインド）、疲労状態（主力疲労=出場選手の平均疲労60以上）
- 効果：攻撃スタイル/守備スタイル/ライン/テンポの変更
- 各ティック開始時に評価。条件が解消されたら基本戦術に戻る。発動は実況で通知

### 7.2 切り札（1試合1回）

| 切り札 | 効果 | リスク |
|---|---|---|
| スーパーサブ | 指名したベンチ選手1人が即投入され、15分間チャンス確率+8%（交代枠を1消費） | 効果終了後、その選手の疲労蓄積2倍 |
| ギアチェンジ | 発動後10分間、中盤スコア+5 | 終了後5分間、中盤スコア−3 |
| 鉄壁モード | 発動後15分間、被チャンス確率−8% | 期間中、自軍チャンス確率−5% |
| パワープレー | 残り10分から発動可。チャンス確率+12% | 被カウンターのゴール確率+10% |

発動条件は戦略ファイルに事前記述（例：「IF 終盤 AND ビハインド」）。
スーパーサブの交代枠はハーフタイムの3枠とは別に後半用として1枠確保される。

## 8. 実況・観戦体験

### 実況ログの例

```
⚽ キックオフ！ 日本代表 vs イタリア代表
   本日の絶好調: キムラ(日本/FW) ／ 絶不調: カトウ(日本/FW), コスタ(伊/MF)

[前半 06分] 日本がボールを支配。ナカムラを軸に細かくつなぐ
[前半 14分] イタリアの狙い通りだ！ 奪って一気に縦へ…グレコのシュートはGKシミズが正面でキャッチ
[前半 22分] 日本、決定機！ キムラの抜け出し…ああっとポスト直撃！
[前半 37分] ⚽ ゴール！ イタリア、少ないチャンスを沈めた！ 決めたのはフェラーリ！ 0-1
[HT] ハーフタイムレポート表示 → 両ベンチが指示ファイルを提出
[HT] 日本ベンチが動く：カトウ→マツモト、テンポ=速い
[後半 71分] 📢 日本、切り札「パワープレー」発動！
[後半 74分] ⚽ ゴール！ 日本、押し込んだ！ 決めたのはマツモト、交代策が的中！ 1-1
[後半 90+2分] イタリア、最後のカウンター…！ シュートは枠の左へ！
🏁 試合終了 1-1
```

### 試合後の出力

- 最終スコア、支配率、シュート数、決定機数、発動した指示・切り札・交代の履歴
- 選手全員の評価点とMVP（最高評価点の選手）
- 短い戦評（「ハイプレスがカウンターの餌食になった」等、判定結果の言語化）
- 乱数シードを表示：同じシード＋同じファイルなら同じ試合を再現可能

## 9. バランス設計の指針

1. **チームの地力は完全同一**（スカッド総合値9000固定）。差は配分＝個性のみ
2. **相性はじゃんけん構造**：どの戦術・どのチーム特色にも天敵がいる
3. **強い選択にはコストを付ける**：ハイプレス→疲労、高ライン→裏、エース型→薄いベンチ
4. **番狂わせ率10〜20%を確保**：確率のクランプとコンディション抽選で保証
5. **チューニングは定数に集約**：相性表・基本確率・クランプ値・生成スクリプトの
   アーキタイプ補正を設定として持ち、総当たりシミュレーションで勝率の偏りを検証する
   （全10チーム×主要戦術の組み合わせで各1000試合、勝率35〜65%に収まることを目標）

## 11. 将来の拡張アイデア

- **スカウティング**：試合前に相手の過去の戦績・よく使う戦術の一部を開示
- **シーズンモード**：勝点でリーグ戦。疲労・負傷が次戦に持ち越し、ターンオーバーが必要に
- **追加チーム**：セネガル（身体能力）、メキシコ（俊敏）、クロアチア（中盤職人）等
- **観戦者投票**：第三者が実況を見ながら勝敗予想して楽しむモード
