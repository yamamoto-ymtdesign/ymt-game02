# テキストイレブン（仮称）

**戦略テキストで戦うサッカーシミュレーションゲーム**

2人のプレイヤー（監督）がそれぞれ戦略を書いたテキストファイル（.md）を用意し、
システムに読み込ませると、試合が確率的にシミュレートされて勝敗が決まるゲームです。

監督にできるのは **試合前の戦略立案** と **ハーフタイムの修正指示** だけ。
キックオフ後は、2分刻みで進む試合の実況を見守ることしかできません。

## コンセプト

> 「ピッチに立つのは選手。だが、試合を決めるのは紙の上の戦略だ。」

- 誰でも、ひな形に沿ってテキストを書くだけでチームを作れる
- 戦略ファイルの内容（戦術の相性・能力配分・状況別指示）が試合結果を変動させる
- 同じ対戦カードでも乱数により毎回違うドラマが生まれる

## 遊び方（想定フロー）

1. `strategies/template.md` をコピーして、自分のチームの戦略ファイルを書く
2. 対戦相手も同様に戦略ファイルを書く
3. 2つのファイルをシステムに読み込ませる
4. バリデーション（ポイント配分のチェックなど）が通ればキックオフ
5. 前半45分（2分刻み）の実況を観戦
6. ハーフタイム：事前に書いておいた修正指示が適用される
7. 後半45分＋アディショナルタイムを観戦
8. 試合結果・スタッツ・MVP発表
