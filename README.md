# テキストイレブン（仮称）

**戦略テキストで戦うサッカーシミュレーションゲーム**

2人のプレイヤー（監督）が国別代表チームを選び、それぞれ戦略を書いたテキスト
ファイル（.md）を用意してシステムに読み込ませると、試合が確率的にシミュレート
されて勝敗が決まるゲームです。

監督にできるのは **試合前の戦略立案** と **ハーフタイムの修正指示（選手交代を含む）**
の2回だけ。キックオフ後は、2分刻みで進む試合の実況を見守ることしかできません。

## コンセプト

> 「ピッチに立つのは選手。だが、試合を決めるのは紙の上の戦略だ。」

- 誰でも、ひな形に沿ってテキストを書くだけで監督になれる
- 10の国別チームは総合力が完全に同一。差は能力の「配分」＝個性だけ
- チームの特色はどこにも明記されない。選手のステータスから読み取れ
- 戦術の相性・スタメン選考・交代采配・コンディションの乱数が試合結果を変動させる

## 起動方法

ブラウザだけで動きます（サーバー不要）。

```
# リポジトリ直下で
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

`index.html` をダブルクリックして直接開いても動作します（GitHub Pages でも公開可能）。

単一ファイル版がほしい場合は `node tools/build-standalone.mjs` を実行すると、
CSS・JSを全てインライン化した `dist/texteleven-standalone.html` が生成されます。
このHTML1枚をブラウザで開くだけで（サーバー不要・外部通信なしで）遊べます。

## 遊び方

### かんたん（クイックプレイ・ファイル不要）

**STEP 1（セットアップ画面）** で両監督のチーム・フォーメーション・スタメン11人・戦術を
選び、**「この設定で試合開始」** を押すだけ。動作チェックや1人での対戦シミュレーションに便利です。

### じっくり（戦略ファイル方式・2人対戦向き）

1. **STEP 1**: 監督名・使用チーム・フォーメーションを選び、ロスター20人の一覧表から
   行をクリックしてスターティングメンバー11人を選び、「戦略ファイルをダウンロード」を押す。
   ファイルは `監督名_日付_時刻.md` の名前で保存され、選んだ選手が入力済み
2. **ダウンロードした .md を編集**: 攻撃スタイルなどの戦術がチェックボックスの
   リストになっているので、`[x]` を付け替えて選ぶ。状況別指示・切り札も編集できる
3. **STEP 2（読み込み画面）**: 両監督の記入済みファイルを読み込ませる。
   バリデーションが2つとも通ると「試合開始」が押せるようになる

### 観戦（共通）

4. キックオフ。全選手の当日のコンディションが発表され、前後半2分刻みで進行。
   **上から見た2Dピッチで選手たちが実際にプレー**（陣形を保ちパスを回し、攻め上がって
   シュート、GKがセーブ、ゴールで演出）する様子を実況と同期して観戦できる
5. **ハーフタイム**: レポート（スコア・選手ごとの疲労/調子/評価点）を確認。
   「HT指示ひな形をダウンロード」→ 編集 → 読み込みで、選手交代（最大3人）と
   制限付きの戦術変更ができる。変更しないなら「変更なしで続行」
6. 試合終了後、スタッツ・選手評価・MVP・乱数シードが表示される
   （同じシードを指定すると同じ試合を再現できる）

## ステータス

Webアプリとして一通りプレイ可能です（セットアップ → 戦略ファイルDL/編集/読み込み →
観戦 → ハーフタイム指示 → 結果）。バランス調整とリーグ戦などの拡張はこれから。
