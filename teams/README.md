# 国別代表チーム

全10チーム。**スカッド総合値（20人×8能力の合計）は全チーム9000で同一。**
チーム差は能力の「配分」にだけあり、それが各チームの個性になる。

どんなチームかは明記していない。紹介文のニュアンスと、選手のステータスの
偏りから読み取ること。それもスカウティングの一部である。
